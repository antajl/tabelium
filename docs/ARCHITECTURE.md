# Архитектура проекта «Сменограф» (Календарь смен 2/2 в ночь)

## 1. Общие сведения и стек технологий
- **Фронтенд:** React 19 + TypeScript (строгая типизация) + Vite 8.
- **Стилизация:** Tailwind CSS v4 (Mobile-First, темная тема по умолчанию, оптимизация под touch-события смартфонов).
- **Иконки:** Lucide React (Moon, Zap, Coffee, Palmtree, Sparkles, Coins, etc.).
- **Сжатие данных для ссылок (шеринг):** `lz-string` (URI-safe compression JSON-состояния).
- **Формат развёртывания:** Progressive Web App (PWA) / статический SPA, который можно запускать локально, на Vercel/Netlify/GitHub Pages или упаковывать в Telegram Web App.

## 2. Модель данных и математика сменного графика

### Базовый цикл (2/2):
- **Опорная дата (`anchorDate`):** `2025-11-02` (Первая ночная смена цикла).
- **Массив цикла (`cycle`):** `['work', 'work', 'off', 'off']` (длина 4 дня).
- **Расчет базового статуса дня $D$:**
  $$\Delta = \text{daysBetween}(\text{anchorDate}, D)$$
  $$\text{mod} = ((\Delta \pmod 4) + 4) \pmod 4$$
  - `0`: `'work'` (Смена в ночь с 20:00)
  - `1`: `'work'` (Смена в ночь с 20:00)
  - `2`: `'off'` (Выходной)
  - `3`: `'off'` (Выходной)

### Слой переопределений (Overrides):
Пользователь не знает подработки на год вперёд, они вносятся точечно за 1–1.5 месяца.
- Структура переопределений: `Record<string, DayOverride>`, где ключ — дата `YYYY-MM-DD`.
- `status`: `'work' | 'off' | 'overtime' | 'vacation'`.
- `note`: опциональная текстовая заметка (например: *«подменил коллегу»*).
- При отображении дня статус из `overrides[date]` имеет наивысший приоритет над базовым циклом. Если день сбрасывается к стандартному графику, запись удаляется из объекта переопределений.

## 3. Модуль «Производственный календарь РФ» (`src/data/holidays.ts`)

### Законодательная база:
- **ст. 112 ТК РФ:** Список нерабочих праздничных дней (Новогодние каникулы 1-8 января, 23 февраля, 8 марта, 1 и 9 мая, 12 июня, 4 ноября).
- **ст. 153 ТК РФ:** Оплата за работу в выходные и нерабочие праздничные дни. Работникам со сменным графиком работа в официальные праздничные дни оплачивается **не менее чем в двойном размере (2X)**.
- **ст. 96 ТК РФ:** Доплата за ночные часы (с 22:00 до 06:00 = 8 часов в каждой 12-часовой смене с 20:00 до 08:00) в размере не менее 20% часового тарифа.

### Логика подсветки:
1. Каждая дата проверяется через функцию `getRussianHolidayInfo(dateStr)`.
2. Если `isDoublePayEligible === true` И статус дня `'work'` или `'overtime'`:
   - На ячейке календаря отображается золотой бейдж **`2X`** со звёздочкой.
   - Ячейка подсвечивается акцентным янтарным кольцом.
   - В статистике месяца смена попадает в счетчик *«2X Праздничные смены»*.

## 4. Механизм шеринга (Поделиться графиком)

- Для того чтобы поделиться своим графиком с родственниками или друзьями, не требуется сложного сервера и регистрации:
  1. Текущие настройки (`config`) и переопределения (`overrides`) сериализуются в компактный JSON.
  2. Строка сжимается через алгоритм `LZString.compressToEncodedURIComponent`.
  3. Формируется ссылка вида: `https://.../#share=H4sIAAAAAAA...`
  4. При открытии этой ссылки приложение переходит в **Гостевой режим («Только чтение»)**:
     - Кнопки редактирования скрыты или заблокированы.
     - Гость видит календарь смен, дни недели, подработки и праздники.
     - Есть кнопка «Перейти к своему графику», которая восстанавливает личные данные из локального хранилища.
