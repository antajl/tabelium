# План развития проекта «Табелиум» (Tabelium Roadmap)

## Этап 1: Начальная реализация (Выполнено ✅)
- [x] Анализ и парсинг исходной Google Таблицы пользователя (все 426 записей с ноября 2025 по декабрь 2026 сохранены в `src/data/initialSchedule.json`).
- [x] Интерактивный календарь с удобным переключением месяца и года (без риска смещения дат).
- [x] Отображение дней недели (Пн, Вт, Ср, Чт, Пт, Сб, Вс) с цветовой дифференциацией выходных.
- [x] 4 основных статуса: Работа (в ночь 20:00), Выходной, Подработка (в ночь), Отпуск.
- [x] Встроенный справочник производственного календаря РФ (ст. 112 ТК РФ) и автоматическая подсветка двойной оплаты (**`2X`**) по ст. 153 ТК РФ.
- [x] Быстрое модальное окно для смены статуса дня по 1 клику/тапу с поддержкой заметок.
- [x] Сводка за месяц: подсчет основных смен, подработок, праздничных 2X смен, отпуска, отработанных и ночных часов, ориентировочной зарплаты.
- [x] Шеринг графика: генерация ссылки только для чтения (`#share=...`) через сжатие `lz-string`.
- [x] Экспорт и импорт резервной копии в JSON.
- [x] Настройки параметров графика (время смены, опорная дата, ставки).
- [x] PWA-манифест и иконка для установки на экран смартфона Android.
