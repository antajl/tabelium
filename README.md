# 🌙 Сменограф — Календарь сменного графика 2/2 в ночь

Современное адаптивное веб-приложение (PWA) для удобного ведения сменного графика **2/2 в ночь** с учетом подработок, отпусков и официальных нерабочих праздничных дней РФ (ст. 112 и 153 ТК РФ) с двойной оплатой.

---

## ✨ Ключевые возможности

1. **График 2/2 в ночь:**
   - Четкое разделение: смена начинается в **20:00** вечера указанного дня и длится до **08:00** утра следующего дня.
   - Базовый цикл 2/2 автоматически рассчитывается на любой год вперед.
2. **Точечный ввод подработок и отпусков:**
   - Подработки вносятся по мере появления (за месяц–полтора) поверх базовых выходных.
   - Быстрое переключение статуса по 1 тапу/клику: *Работа*, *Выходной*, *Подработка*, *Отпуск*.
3. **Производственный календарь РФ (ст. 112 ТК РФ):**
   - Встроенный справочник праздников РФ (Новогодние каникулы, 23 февраля, 8 марта, 1 и 9 мая, 12 июня, 4 ноября).
   - Автоматическая подсветка золотым бейджем **`2X Оплата`** 💰 смен, выпадающих на праздничные дни по ст. 153 ТК РФ.
4. **Сводка и статистика за месяц:**
   - Количество основных смен и подработок.
   - Количество смен с двойной оплатой.
   - Дни отпуска.
   - Отработанные часы и ночные часы (по ст. 96 ТК РФ).
   - Калькулятор ориентировочного заработка.
5. **Шеринг графика (Поделиться):**
   - Генерация ссылки только для чтения (`#share=...`), которую можно отправить в Telegram или WhatsApp.
   - Человек сможет смотреть график без риска что-то сломать.
6. **Экспорт и импорт:**
   - Резервная копия всех данных в JSON-файл в один клик.
7. **Работа на Android и ПК (PWA):**
   - На Android можно нажать *«Установить приложение»* / *«Добавить на главный экран»*, и сайт будет открываться как отдельное полноэкранное мобильное приложение без адресной строки.

---

## 🚀 Запуск в режиме разработки

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

## 📦 Сборка для продакшена

```bash
npm run build
```
Готовая сборка находится в папке `dist/` и готова к загрузке на любой статический хостинг (Vercel, Netlify, Cloudflare Pages, GitHub Pages).
