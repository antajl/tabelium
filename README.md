# Табелиум (Tabelium) — Календарь сменного графика 2/2 в ночь

Эстетичное и быстрое веб-приложение для планирования и учета сменного графика работы (2/2 в ночь с 20:00 до 08:00), подработок, отпусков и официальных праздников РФ с расчетом повышенной оплаты.

---

## Особенности проекта

- **Годовой обзор 365 дней**: весь год виден на одном экране без лишнего скролла.
- **Ночные смены (20:00 – 08:00)**: точный учет переходящих через полночь смен и 8 ночных часов в соответствии со ст. 96 ТК РФ.
- **Праздники РФ и двойная оплата (2X)**: автоматическое определение нерабочих праздничных дней по ст. 112 ТК РФ и подсветка смен с двойной оплатой по ст. 153 ТК РФ.
- **Подработки и отпуска**: удобное точечное нанесение дополнительных ночных выходов и периодов отпуска поверх базового цикла.
- **Отпуска коллег**: возможность сопоставлять свой график с отпусками сменщиков и коллег.
- **Шеринг без сервера**: генерация ссылки только для чтения с алгоритмом сжатия данных прямо в URL.
- **Резервное копирование**: экспорт и импорт базы графика в формате JSON.
- **PWA-режим**: поддержка установки на домашний экран смартфона как автономное приложение.
- **Стиль оформления**: выдержанная визуальная палитра в теплых тонах слоновой кости, бронзы и бумаги без визуального шума.

---

## Стек технологий

- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React** (векторная иконографика)
- **lz-string** (сжатие URL для шеринга)

---

## Запуск и разработка

```bash
# Установка пакетов
yarn

# Запуск локального сервера разработки
yarn dev

# Сборка проекта для публикации
yarn build

# Проверка кода
yarn lint
```

## Развёртывание в сети

Проект представляет собой клиентское SPA-приложение и может быть опубликован на любом статическом хостинге:

1. **Vercel**: импортируйте репозиторий, настройки сборки подхватятся автоматически (правила маршрутизации настроены в `vercel.json`).
2. **Cloudflare Pages**: каталог сборки `dist`, команда `yarn build` (правила перенаправления находятся в `public/_redirects`).
3. **GitHub Pages**: сборка публикуется в ветку `gh-pages` через стандартный action.
