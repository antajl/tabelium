# Инструкция для AI-агентов по проекту «Сменограф»

## Контекст пользователя
- Пользователь работает **2/2 в ночь** (начало смены в **20:00**, окончание в **08:00** утра следующего дня, длительность 12 часов, 8 ночных часов).
- «Работа» = дата, в вечер 20:00 которой начинается смена.
- «Выходной» = ночь отдыха (не идёт на работу).
- Основной график известен заранее на весь год вперед (циклический 2/2).
- Подработки («Подработка») известны точечно за 1–1.5 месяца.
- Отпуск («Отпуск») проставляется блоками.

## Законодательство РФ
- Официальные нерабочие праздничные дни определены статьей **112 ТК РФ** (Новогодние каникулы 1-8 января, 23 февраля, 8 марта, 1 и 9 мая, 12 июня, 4 ноября).
- Работа в эти дни оплачивается **не менее чем в двойном размере (2X)** по ст. 153 ТК РФ.
- В календаре такие смены помечаются золотым бейджем `2X`.

## Архитектура и стек
- React 19 + TypeScript + Vite + Tailwind CSS v4.
- Все типы в `src/types/schedule.ts`.
- Вся логика расчетов в `src/utils/scheduleEngine.ts`.
- Исходные данные пользователя (426 дней с 01.11.2025 по 31.12.2026) в `src/data/initialSchedule.json`.
- Праздники в `src/data/holidays.ts`.
- Шеринг: `lz-string` URL Hash `#share=...`.
- Режим `isReadOnly` активируется автоматически при открытии ссылки `#share=`.

## Правила доработки кода
- Всегда соблюдать строгую типизацию TypeScript (`verbatimModuleSyntax: true` требует `import type { ... }`).
- Проверять сборку командой `npm run build`.
- Сохранять мобильную адаптивность (touch targets не менее 44px, bottom sheets для мобилок).
